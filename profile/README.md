# Public Media Work

Tools for public media institutions, built by [@mriechers](https://github.com/mriechers). Most of it grew out of digital production work at PBS Wisconsin: metadata, analytics, social, editorial, and the agent workflows that connect them. Where a tool is general enough, it's published here for anyone in public media to use.

## Private work

Most of the work is still private. It touches internal data, unpublished content, or shared station accounts, so it stays closed until it's been reviewed. Here's what it does, by area.

<!-- BEGIN:capabilities -->
**Analytics and reporting.** A central store for the station's digital numbers across platforms, with skills that turn it into reports. Tools that judge video performance by public-media goals, not raw view counts alone. A crawler that checks a large website for rendering bugs, accessibility problems, and leftovers from old migrations.

**Social and scheduling.** Tools that draft posts from newly published stories, show how each post will look on each platform, and hold everything in a queue until a person approves it. Nothing goes out on its own.

**Editorial and metadata.** Copy-editing skills that apply house style to titles, descriptions, keywords, and transcripts, and that know where a department is allowed to differ. A dashboard for producers. Automations that keep production tasks and the content calendar in step with the notes people work from, and that cut down on time-tracking busywork.

**Design and brand.** Brand guidelines turned into machine-readable rules and design tokens, plus skills that answer a style question with a citation or review a page or graphic against the guide.

**Research and AI safety.** A research desk for sourced, verified background research, set up so working files stay on the machine where they were made. Guidelines for how agents should behave, where each rule cites the source it rests on and every change records how much AI was involved.

**Operations.** Everyday tooling: checks on which agent skills run where, helpers for the digital asset library, and an archive of production run data used to measure how the public tools perform.

Some of this will go public once it's cleared. When it does, it moves to the table above.
